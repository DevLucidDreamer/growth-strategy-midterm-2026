# 전략 학습실

4차산업혁명시대의 기업성장전략 2–7주차 교안과 두 시험 후기를 바탕으로 재구성한 학습용 예상문제. 실제 기출·출제를 보장하지 않습니다.

- 모의고사 1–4회: 각 30문항, 객관식 15 + OX 15. 제출 후 채점과 해설.
- 추가 연습 100문항. 무한 연습은 모의고사 120 + 추가 100 = 총 220문항을 한 바퀴씩 셔플로 반복. 선택 즉시 정답 공개.
- 오답 자동 수집과 재풀이, 개념 검색·비교표·인쇄.
- 시간제한·횟수 제한 없음. 진행 중 모의고사와 기록은 브라우저 localStorage에 저장.
- 110개 개념 문항쌍을 객관식과 OX로 구성. 회차 간 동일 ID는 중복되지 않지만 핵심 개념은 형식을 바꿔 재등장합니다.

교안 원본·응시명단·시험 후기 원문은 공개 저장소에 포함하지 않습니다. 근거는 주차와 PDF 페이지 순서로 표시합니다. 후기에서 언급된 주제를 우선 반영하며 실제 출제 빈도를 추정하지 않습니다. 특히 기술적 자원 분류는 5주차 10–11쪽의 교안 기준을 따릅니다.

## 실행

index.html을 정적 호스팅합니다. 문제 원천은 facts.txt, 생성기는 build.mjs입니다.

```sh
node build.mjs
node --check app.js
node verify.mjs
```

GitHub Pages는 main 브랜치 루트에서 게시합니다. 학습 기록은 서버로 전송되지 않으며 다른 기기로 동기화되지 않습니다. 브라우저 데이터를 지우면 기록도 삭제됩니다.
