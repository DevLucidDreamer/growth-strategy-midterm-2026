# 전략 학습실

4차산업혁명시대의 기업성장전략 교안과 시험 후기를 바탕으로 재구성한 학습용 예상문제입니다.

## 2026-11-13 기말고사 범위 추가

- 화면 상단의 중간고사·기말고사 탭에서 학습 범위를 선택합니다. 중간고사는 기존 2~7주차 자료와 저장 기록을 사용합니다.
- 기말고사는 현재 9~11주차 교안 기준으로 주차별 요약과 예상문제 73문항을 제공합니다. 주차·후기 관련 주제·문제 유형으로 연습하고 오답을 다시 풀 수 있습니다.
- 기말고사 대시보드와 주차별 요약·문제 메뉴에서 [9~11주차 코넬 노트 PDF](output/pdf/final-cornell-notes.pdf)를 내려받을 수 있습니다.
- 모의고사는 과거 후기의 비율을 적용해 객관식 30문항과 OX 10문항으로 출제합니다. 시험 진행, 최근 결과 10회, 오답은 기말고사 기록에 저장됩니다.
- 12~15주차 교안이 추가되면 `semester-data.js`의 `SEMESTER_WEEKS`에 주차·주제·문항을 추가합니다. 문항 ID는 기존 기록과 연결되므로 새 문항에 고유 ID를 지정합니다. 후기에 나온 항목 중 추가 교안에서 확인할 주제는 주차별 요약 목록 아래에 표시합니다.
- 작업 폴더의 `기말고사 시험정보.txt`에 제공된 후기와 범위 메모를 정리했습니다.

## 2026-10-20 업데이트

- 실전 모의고사 5~8회: 족보 18개 주제를 매회 포함하는 고정 객관식 30문항씩, 총 120개의 새 변형문제. 5회 기본 변형·6회 사례 적용·7회 개념 구별·8회 종합 점검. 회차별 이어 풀기·채점·주제별 결과·오답 재시험을 지원하며, 기존 랜덤시험과 회차 번호가 섞이지 않도록 구분합니다.

- 최종 실전 모의고사 탭: 시험정보의 18개 주제만으로 객관식 30문항 또는 객관식 24+OX 6문항을 구성합니다. 모든 주제를 매회 포함하고, 정답은 제출 후 공개합니다. 진행·최근 10회 결과 저장, 표시한 문제 재확인, 주제별 성적·오답 재시험을 제공합니다. 실제 문항 수·시간·형식별 비율은 후기에 없어 연습용으로 명시합니다. 광의·협의 정의 등 최종시험 전용 보충문항 3개는 출처·보충 여부를 해설에 표시합니다.
- 최종점검 탭: 시험정보.txt의 두 후기에 언급된 18개 주제만 정리한 요약과 기존 문제 중 선별한 149문항. 주제별·객관식/OX·이 범위 오답만 풀이, 진행 자동 저장. 5~8회 변형문제 추가 후 전체 문제 수는 750문항입니다.
- 전체 750문항: 기존 220 + 세부 객관식 331 + 문장판단 OX 79 + 족보 변형 120. 총 객관식 561, OX 189.
- 원본 151쪽 점검표: 내용 124쪽, 표지·절 구분 24쪽, 반복·연결 3쪽. 내용 페이지마다 문항이 연결되지만 모든 문장을 문제화했다는 뜻은 아닙니다.
- 숫자·연도·학자·기업사례·비교표·절차, VRIN 결과표, 컨설팅 가치사슬, 벤치마킹, Value Driver 과제·시기 반영.
- 암기카드 561장: 정답 가림, 외움·다시보기, 주차·미암기 필터. 카드 표시는 문제 채점과 별도로 저장.
- 기존 고정 모의고사 4회 보존. 랜덤 모의고사: 30문항, 객관식·OX 각 15, 6개 주차 모두 포함, 각 주차·유형 최소 2문항.
- 주차·페이지·세부문제·미풀이·유형 필터, 교안순·무작위 연습, 즉시 해설, 오답 재풀이, 연습진행 자동 저장.
- 기존 문항 ID·답·선택지를 유지해 오답·시험기록 보존. 과거 기록에는 최근 정답 여부가 없어 슬라이드의 최근 전부 정답 표시는 다시 풀어야 생깁니다.

교안 원본과 응시명단은 사이트 파일에 포함하지 않습니다. 문제 근거는 주차와 PDF 페이지 순서입니다. 기술적 자원 분류, 세금·법률·기업사례 수치는 교안 기준입니다. 다각화 경계 70%·95%가 겹치는 사례는 피합니다.

## 실행·검증

빌드 의존성 없이 루트 index.html을 정적 호스팅합니다.

```sh
node build.mjs
node --check app.js
node --check comprehensive.js
node --check semester-data.js
node --check semester.js
node verify.mjs
node test-flows.mjs
node test-final.mjs
node test-final-exam.mjs
node test-report-papers.mjs
python -m http.server 8765 --bind 127.0.0.1
```

facts.txt, details.txt, judgments.txt, report-papers.txt에서 questions.js와 study-data.js를 생성합니다. build.mjs는 build-report-papers.mjs도 실행해 회차 메타데이터를 생성합니다. 원본 PDF와 텍스트 추출물은 배포하지 않습니다.

GitHub Pages는 main 브랜치 루트에서 게시합니다. 기록은 localStorage에만 저장하며 서버 전송·기기간 자동 동기화는 하지 않습니다. 브라우저 데이터를 지우면 기록도 삭제됩니다.
